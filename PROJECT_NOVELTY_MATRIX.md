## Closest-Project Checks

- DocuTrace is closest to the embedded DocuTrace concept, but the standalone workflow adds version comparison, citation verification, structured fields, decision history, and independent tests.
- ReviewFlow is closest to SignalOps in its approval model, but it handles staged policy execution and exception responses rather than incident classification or dispatch.
- FrameForge Inspect preserves the creative-review domain while replacing metadata-only simulation with real pixel analysis and local file handling.
- QueueCast replaces PilotMap because scenario forecasting, uncertainty, and staffing tradeoffs teach more than generic AI-opportunity scoring.
