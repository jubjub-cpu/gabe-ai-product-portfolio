# Portfolio Strategy

## Positioning

Gabe is presented as an AI Digital Product Developer who uses AI-assisted development, prompt engineering, workflow design, visual refinement, testing, and iteration to turn business workflow problems into usable digital products.

## Project Selection

The completed five-product foundation covers the requested categories:

1. AI operations intelligence: SignalOps Triage.
2. AI workflow automation or agent system: ReviewFlow Agent.
3. Document intelligence: DocuTrace Desk.
4. Multimodal or creative media product: FrameForge QA.
5. AI opportunity and workflow design: PilotMap AI.

Phase Two completes the portfolio with five distinct standalone products. EvalDeck Studio adds formal AI-output evaluation and release gates. FlowReplay Console adds API design, event retries, and idempotency. VoiceGauge Local adds real browser audio decoding, PCM analysis, visual signal evidence, and a strict local-file privacy boundary. ColdChain Sentinel adds multivariate telemetry, persistence-aware anomaly detection, clear hysteresis, and sensor-health monitoring. CivicCase Redact adds offset-preserving privacy review, reversible decisions, manual redaction, and value-free release artifacts.

## Why Static First

A static browser suite avoids unnecessary setup friction, keeps the main workflows easy to review, and can be hosted on any free static service. Git for Windows was installed for publishing, but the portfolio itself does not require a Node.js build chain.

## Truthfulness Rules

- Do not claim live AI execution where deterministic demo logic is used.
- Do not claim customer use, revenue, savings, or production deployment.
- Do not imply Gabe has traditional engineering credentials.
- Do show product thinking, AI workflow design, testing, and responsible scope control.
